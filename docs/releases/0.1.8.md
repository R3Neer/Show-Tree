# Show-Tree 0.1.8 — Direct tree output

Show-Tree 0.1.8 removes the banner that repeated the command name before every tree.

## Changes

- Interactive Nushell and PowerShell output now begins with the root path.
- Text saved from a Nushell tree uses the same direct presentation, without a `SHOW-TREE` banner.
- Empty results begin with the existing `No matching paths.` status.

## Compatibility

- Traversal, sizes, native rows, and command options are unchanged.
- `.showtree` remains schema version 1; `producer_version` advances to 0.1.8.
