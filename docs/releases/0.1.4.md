# Show-Tree 0.1.4

Show-Tree 0.1.4 cleans up the visibility model introduced in 0.1.3: files remain part of the normal tree, hidden entries become an explicit opt-in again, and the old `long` switch is replaced by the more useful inverse operation, `short`.

## Visibility controls

- Removes the Show-Tree `--long` / `-l` option in Nushell and `-Long` / `-l` in PowerShell. Files are already part of the default output, so an option whose only job was to request the default had no useful semantics.
- Restores `--all` / `-a` in Nushell and `-All` / `-a` in PowerShell as a real visibility control. Hidden entries are omitted by default and included only when `all` is requested.
- Adds `--short` / `-s` in Nushell and `-Short` / `-s` in PowerShell for a directories-only view.
- `short` changes row visibility only. Directory sizes still include the visible files beneath them, preserving useful size totals while suppressing file rows.
- Default recursion remains unlimited unless an explicit maximum depth is supplied.

## Hidden-entry reminder

- A live interactive tree produced without `all` now shows a concise reminder that hidden entries are omitted and points to `--all (-a)` or `-All (-a)`.
- In Nushell the reminder is carried as private presentation metadata, so row-preserving operations such as `where`, `sort-by`, `take`, and `$ans.last` keep the reminder along with the reconstructed tree.
- The reminder is deliberately not part of the public Show-Tree rows and is not written by tree-aware `save`.
- PowerShell likewise emits the reminder only for an interactive invocation. Pipeline output remains clean, so `Show-Tree ... | Set-Content tree.txt` writes only the tree.

## Cross-platform hidden semantics

- Dot-prefixed entries are hidden by default on every platform.
- PowerShell also respects the Windows filesystem Hidden attribute.
- Nushell now mirrors that behavior on Windows by combining the structured `du` traversal with Nushell's platform-native visible-entry rules, so a file carrying the Windows Hidden attribute is omitted unless `--all` is supplied.

## Persistence and pipelines

- The public Nushell row contract remains `name`, `type`, `size`, `children`, and `path`.
- Human-tree saves still contain the banner, Unicode branches, sizes, and total without ANSI escapes. The interactive hidden-entry reminder is excluded.
- `.showtree`, `to showtree`, and `from showtree` remain fully supported. Visibility is resolved before a snapshot is created, so a default, `--all`, or `--short` snapshot stores exactly the rows selected by that invocation.
- The `.showtree` schema remains version 1; only `producer_version` advances to 0.1.4.
- Existing tree-aware filtering, sorting, orphan promotion, explicit JSON/NUON conversion, and builtin `%save` escape behavior are preserved.

## Validation and documentation

- Adds explicit tests for default visible files, hidden omission, `all`, `short`, unlimited recursion, maximum-depth filtering, and directory size accounting.
- Adds real REPL coverage for the interactive reminder, `--all`, `--short`, transformed trees, `$ans.last`, and `.showtree` reopening.
- Adds Windows coverage for both dot-prefixed names and the filesystem Hidden attribute in Nushell and PowerShell.
- Installer and pipeline tests verify that the interactive reminder cannot leak into saved human trees or PowerShell piped output.
- README documentation was reviewed iteratively after implementation and updated to match the final cross-platform behavior and the organized `src/` layout.
