# Show-Tree 0.1.1

Show-Tree 0.1.1 makes the human tree representation behave like a first-class Nushell value at the point where users save it, while preserving the native structured rows everywhere else in a pipeline.

## Highlights

- Installs a thin Nushell `save` wrapper that recognizes representable Show-Tree values through their private lineage metadata.
- `show-tree ... | save tree.txt` now writes the same R3CLI tree that the REPL displays, with Unicode branch glyphs and no ANSI colour escapes.
- Tree-aware saving survives row-preserving transformations such as `where`, `take`, `drop`, `reverse`, and `sort-by`, so the saved forest matches the transformed result rather than the original traversal.
- The wrapper delegates every non-Show-Tree value to Nushell's builtin `%save` with the same filename and standard flags. `%save` remains an explicit escape hatch when builtin behavior is desired directly.
- Explicit conversions stay explicit: `show-tree ... | to json | save file.json` and other serializers consume the native rows before `save`, so machine-readable workflows are unchanged.
- No `--render`, `--output`, or Show-Tree-specific file option is added. Saving remains a normal shell pipeline operation.
- PowerShell's installed `Show-Tree` wrapper now exposes plain tree lines on the success pipeline when the command is piped, allowing `Show-Tree ... | Set-Content tree.txt` while keeping normal interactive R3CLI rendering unchanged.
- Updates the Nushell and PowerShell help versions to 0.1.1.

## Validation

CI covers direct and filtered Show-Tree saves, preservation of explicit JSON serialization, delegation of unrelated JSON values to builtin `save`, installer import of the tree-aware wrapper, normal REPL rendering and `$ans.last`, structured flat rows, PowerShell pipeline-to-file output without ANSI escapes, installer repair, idempotent reinstall, and vendored R3CLI integrity.

The public Nushell data contract remains `name`, `type`, `size`, `children`, and `path`. Tree lineage remains private metadata used only to reconstruct presentation.
