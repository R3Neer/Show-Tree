# Show-Tree 0.1.10 — Native clipboard compatibility

Show-Tree 0.1.10 works with Nushell's experimental native clipboard commands.

## Changes

- With `NU_EXPERIMENTAL_OPTIONS=native-clip`, `clip paste` uses Nushell's native clipboard implementation.
- Show-Tree keeps its `clip copy` wrapper, so `show-tree | clip copy` copies the rendered tree instead of a flat table.

## Compatibility

- Native rows, filters, sorting, and `.showtree` schema version 1 are unchanged.
- `producer_version` advances to 0.1.10.
