# Show-Tree 0.1.6

Show-Tree 0.1.6 is a focused Nushell integration hotfix for child processes that reload the user configuration.

## Fixed

- Fixes `show-tree-display.nu` failing with `Can't convert to boolean` when a child Nushell process inherits `SHOW_TREE_DISPLAY_HOOK_INSTALLED=true` from a parent process and then loads Show-Tree again through `config.nu`.
- The display-hook marker is now considered active only when it is the boolean value `true` in the current Nushell process. An inherited environment-string value such as `"true"` is treated as stale process-local state, so the child installs its own display hook normally.
- Adds a regression test that reproduces the parent-process to child-process inheritance case and verifies that the child can load the display module successfully.

## Why this matters

Interactive use was generally unaffected because the marker remains a real boolean inside the process that installed the hook. The failure appeared in automation that launches a new Nushell process with `--config`, which is a legitimate way to load commands imported from `config.nu` such as Show-Tree.

## Compatibility

- No command-line options change.
- The public Nushell row contract is unchanged.
- `.showtree` remains schema version 1; `producer_version` advances to 0.1.6.
- PowerShell behavior is unchanged apart from reporting version 0.1.6 in help output.
- This is a patch release over 0.1.5.

## Validation

The fix is covered by a dedicated child-process regression test, and the existing Show-Tree CI suite passed before preparing this release. The release workflow also reruns the relevant Nushell syntax, rendering, traversal and structured-output checks against the 0.1.6 working tree before publishing.
