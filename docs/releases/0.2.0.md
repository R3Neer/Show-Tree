# Show-Tree 0.2.0 — Depth boundaries and size completeness

Show-Tree 0.2.0 makes depth-limited trees show files and folders consistently,
and distinguishes counted sizes from complete sizes in both PowerShell and Nushell.

## Boundary folders remain visible

`--max-depth` / `-MaxDepth` still limits directory traversal. Direct subfolders
at the boundary now appear without inspecting their contents, alongside the
files already shown at that level. Their uncounted contents do not contribute
to the size total.

For example, `show-tree D:/Universidad/Clases -d 1` now includes `Estilos` and
`Plantillas` under `Gobierno` instead of omitting those folders:

```text
├── 📁 Gobierno (≥ 82.94 KiB)
│   ├── 📁 Estilos (≥ 0 B)
│   ├── 📁 Plantillas (≥ 0 B)
│   ├── Calendario_lectivo.md (928 B)
│   …
```

## Native size completeness

- Nushell adds the boolean `size_complete` column to its public rows. `size`
  remains a native `filesize` for filtering, sorting, and arithmetic.
- Unvisited folders have `size_complete = false`. Incompleteness propagates to
  ancestor folders and the total.
- Human trees, saved text, and clipboard text prefix incomplete sizes with `≥`.
  Lower bounds round downward, so formatting cannot overstate the counted bytes.
- `≥ 0 B` means no bytes have been counted, not that the folder is empty.
- Empty-folder hiding retains folders whose contents have not been inspected.
- An inaccessible boundary folder remains visible with incomplete size instead
  of aborting the Nushell traversal.

Completeness is evaluated under the active visibility and file filters.
Intentionally excluded files and hidden entries do not make a size incomplete.
No recursive search is added to discover whether an unvisited folder has files.

## Compatibility

- This is a minor feature release following 0.1.11.
- Nushell rows now contain `name`, `type`, `size`, `size_complete`, `children`,
  and `path`. Consumers expecting exactly five columns should update their selection.
- `.showtree` remains envelope schema version 1 and preserves the new field;
  `producer_version` advances to 0.2.0.
- Older snapshots remain readable. Directory rows without completeness information
  display conservatively with `≥`, since their original traversal limit is unknown.
- Unlimited traversal, hidden-entry controls, file filters, and link handling
  retain their existing semantics.

## Validation

- Tested locally on Windows with PowerShell 7.6.6 and Nushell 0.115.1, including
  the installed commands in the terminal against a real vault.
- Added automated coverage for depths 0–3 and unlimited traversal, empty folders,
  zero-byte files, Unicode names, dot and Windows-attribute hidden folders,
  minimum-size and exclusion filters, multiple roots, and lower-bound rounding.
- Verified filtered rows, human saves, clipboard text, `.showtree` round trips,
  legacy snapshots, and malformed completeness fields.
- Existing traversal, rendering, persistence, Windows-root, and performance checks
  passed. Junction behavior was also checked locally; temporary fixtures were removed.

## Distribution

The release includes the source package `Show-Tree-0.2.0.zip` with the vendored
R3CLI dependency and `Show-Tree-0.2.0.zip.sha256` for integrity verification.
Open a new Nushell session after updating to load the new command definitions.
