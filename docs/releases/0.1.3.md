# Show-Tree 0.1.3

Show-Tree 0.1.3 fixes the default traversal contract and reorganizes the repository so the installed command is complete by default and implementation code lives under a conventional `src/` tree.

## Fixes

- Fixes the main default-output bug: `show-tree` no longer returns or renders only directories unless `--long` / `-Long` is supplied. File rows are included by default in both Nushell and PowerShell.
- Removes the second implicit visibility filter at the same time: hidden and dot-prefixed entries are now included by default. Nushell always gathers them with `du --all`; PowerShell traverses with `Get-ChildItem -Force` without discarding them afterwards.
- Keeps recursion unbounded by default. With no explicit filters, `show-tree` now means the complete recursive tree: directories, files, hidden entries and all descendants.
- `--long` / `-l` and `--all` / `-a` remain accepted as backwards-compatible no-ops so existing scripts do not break simply because completeness became the default.
- Explicit filtering remains intact: maximum depth, minimum file size, exclusions, empty-folder hiding and dereference behavior continue to work.

## Repository layout

- Moves Nushell implementation code to `src/nushell/`:
  - `show-tree.nu`
  - `show-tree-display.nu`
  - `show-tree-format.nu`
  - `show-tree-save.nu`
- Moves the PowerShell implementation to `src/powershell/Show-Tree.ps1`.
- Keeps the repository root focused on user-facing installers, `README.md`, dependency metadata and top-level project folders.
- Updates the installer to reference `src/` directly; installed `show-tree`, `save`, `to showtree`, `from showtree` and PowerShell `Show-Tree` names are unchanged.

## Preserved behavior

- Native Nushell rows remain `name`, `type`, `size`, `children`, and `path`.
- Row-preserving pipelines still reconstruct truthful trees through private lineage metadata.
- Saving to an ordinary filename still writes the human R3CLI tree.
- `.showtree` persistence, `to showtree` / `from showtree`, raw semantics and reopened-tree rendering are unchanged apart from the producer version advancing to 0.1.3.
- PowerShell pipeline-to-file behavior remains supported without adding an output-specific option.

## Validation

CI now explicitly creates root files, hidden files and files several directories deep and verifies that a no-flag Show-Tree call includes all of them in both Nushell and PowerShell. It also verifies that `--max-depth` / `-MaxDepth` still limits traversal, that the historical completeness flags do not change the default result, and that the existing structured pipelines, human saves, `.showtree` round trips, raw behavior, live REPL rendering, installer repair, idempotent reinstall and vendored dependency checks still pass.
