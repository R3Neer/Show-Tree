# Show-Tree 0.1.11 — Unicode clipboard fix on Windows

Show-Tree 0.1.11 fixes corrupted tree glyphs and accented names copied from Nushell on Windows when the console uses a code page such as 850.

## Fixed

- `show-tree | clip copy` sends UTF-8 text to the Windows clipboard explicitly instead of relying on `clip.exe` to decode the terminal's code page.
- The console's original input code page is restored after copying.

## Compatibility

- Native rows, filters, sorting, and `.showtree` schema version 1 are unchanged.
- `producer_version` advances to 0.1.11.
