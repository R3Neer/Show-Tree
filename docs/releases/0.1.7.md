# Show-Tree 0.1.7

Show-Tree 0.1.7 is a Windows traversal hotfix for filesystem roots that contain compatibility junctions.

## Fixed

- Fixes duplicate public `path` values when scanning Windows roots such as `C:/`.
- The issue affected junction-backed compatibility entries including paths that could normalize onto `C:\\Users` or `C:\\ProgramData`.
- Path normalization now uses `path expand --no-symlink`, preserving the lexical identity of junction entries instead of resolving them onto their targets.
- `.showtree` persistence therefore no longer fails with `Show-Tree row paths must be unique` for normal shallow Windows-root scans.

## Regression coverage

- Adds a permanent Windows-root regression test.
- The test scans `C:/` with and without `--all`, asserts public path uniqueness, and verifies that the result can be serialized and reopened as `.showtree`.
- The fix was independently reproduced and validated on GitHub Actions Windows runners before this release was prepared.

## Compatibility

- No command-line options change.
- The public Nushell row contract remains `name`, `type`, `size`, `children`, and `path`.
- `.showtree` remains schema version 1; `producer_version` advances to 0.1.7.
- PowerShell traversal semantics are unchanged apart from reporting version 0.1.7 in help output.
- This is a patch release over 0.1.6.
