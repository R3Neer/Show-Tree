# Show-Tree 0.1.9 — Copy the rendered tree

Show-Tree 0.1.9 adds a Nushell clipboard command for copying the human tree.

## Changes

- `show-tree D:/Tools | clip copy` copies the plain tree, with branches and sizes, instead of the native row table.
- Filtered and sorted Show-Tree results copy the tree represented by the remaining rows.
- Ordinary values passed to `clip copy` are copied as text.
- The Nushell installer adds the command to the Show-Tree config block.

## Compatibility

- Native rows and existing structured pipelines remain unchanged.
- The clipboard command uses the system clipboard utility: `clip.exe` on Windows, or an available `pbcopy`, `wl-copy`, `xclip`, or `xsel` elsewhere.
- `.showtree` remains schema version 1; `producer_version` advances to 0.1.9.
