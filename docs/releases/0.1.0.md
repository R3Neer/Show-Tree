# Show-Tree 0.1.0

Show-Tree 0.1.0 introduces the first release of the cross-shell size-aware tree, with a native Nushell data model that remains pleasant to use interactively.

## Highlights

- Adds the Nushell `show-tree` command backed by structured `du --long` traversal and normalized logical file sizes.
- Returns one flat native row per visible filesystem node with `name`, `type`, `size`, and `path` fields. Descendants are no longer hidden inside nested `children` tables.
- Adds a Nushell display integration that renders an unchanged direct result as the R3CLI tree while preserving the native table for pipelines, captures, serialization, and explicit `| table` use.
- Preserves the same presentation metadata through Nushell's `$ans.last`, so recalling the last untouched Show-Tree result redraws the tree instead of exposing an accidental implementation table.
- Keeps hierarchy-only data such as branch glyphs and depth outside the public machine contract.
- Falls back to Nushell's ordinary display path after filtering, sorting, selecting, or otherwise transforming the returned rows, avoiding stale tree redraws.
- Provides matching depth, minimum-size, exclude, long-file, dot-entry, dereference, and empty-folder controls in PowerShell and Nushell.
- Bundles verified private PowerShell and Nushell R3CLI adapters; users do not need a separate R3CLI checkout or Python runtime.
- Adds a Nushell installer and upgrade-safe `config.nu` integration, including repair from `nu --no-config-file`, backup of the previous config, marker validation, and idempotent reinstall.
- Keeps the existing PowerShell implementation and profile integration alongside the Nushell command.

## Validation

CI validates Nushell 0.115.1 syntax, flat structured output, serialization, explicit table readability, direct R3CLI rendering in a real pseudo-terminal REPL, `$ans.last` redisplay, preservation of Nushell's normal display hook, installer repair and backup behavior, idempotent reinstall, vendored dependency integrity, and PowerShell profile installation.

The display integration deliberately hooks only interactive result rendering. Captured and redirected values remain ordinary native Nushell data.
