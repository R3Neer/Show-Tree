# Show-Tree 0.1.0

Show-Tree 0.1.0 introduces the first release of the cross-shell size-aware tree, with native Nushell data that keeps a tree-first interactive presentation through ordinary pipelines.

## Highlights

- Adds the Nushell `show-tree` command backed by structured `du --long` traversal and normalized logical file sizes.
- Returns one flat native row per visible filesystem node with `name`, `type`, `size`, `children`, and `path` fields. Every descendant is a first-level row; `children` is only a flat list of direct child names, never nested child records.
- Uses R3CLI as the automatic REPL representation of a representable Show-Tree value while leaving the underlying result as ordinary native Nushell data.
- Keeps the R3CLI tree view after row-preserving transformations such as `where`, `take`, `drop`, `reverse`, and `sort-by`, rebuilding the hierarchy from exactly the rows that remain instead of redrawing a stale original tree.
- Promotes retained nodes to the nearest retained ancestor when filtering removes intermediate parents; nodes with no retained ancestor become visual roots labelled by full path.
- Makes sorting hierarchy-safe: parents always precede descendants, while the transformed row order controls roots and siblings where hierarchy permits it.
- Uses explicit `| table` as the intentional flat-table view. JSON, NUON, captures, and other machine operations consume the same native rows directly.
- Falls back to Nushell's normal display when a transformation removes required tree fields or changes the result into a non-tree shape such as a scalar list or grouped record.
- Preserves tree lineage through Nushell's `$ans.last`, so recalling an original or filtered representable result redraws that result as a tree.
- Keeps lineage-only information such as parent paths outside the public machine contract and outside serialized output.
- Provides matching depth, minimum-size, exclude, long-file, dot-entry, dereference, and empty-folder controls in PowerShell and Nushell.
- Bundles verified private PowerShell and Nushell R3CLI adapters; users do not need a separate R3CLI checkout or Python runtime.
- Adds a Nushell installer and upgrade-safe `config.nu` integration, including repair from `nu --no-config-file`, backup of the previous config, marker validation, and idempotent reinstall.
- Keeps the PowerShell implementation and profile integration alongside the Nushell command.

## Validation

CI validates Nushell 0.115.1 syntax, flat structured output, direct-child lists, serialization, explicit table readability, direct R3CLI rendering in a real pseudo-terminal REPL, filtered-tree reconstruction, orphan promotion, hierarchy-safe sorting, `$ans.last` redisplay, fallback for non-representable transformations, preservation of Nushell's normal display hook, installer repair and backup behavior, idempotent reinstall, vendored dependency integrity, and PowerShell profile installation.

The display integration affects only interactive result rendering. Captured and redirected values remain native Nushell data, and explicit renderers such as `table` or `to json` keep their normal semantics.
